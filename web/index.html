        About BigMoves

        BigMoves suggests which trotros to take between two places in Greater Accra, where to change, and a likely journey time. This is a prototype for review.

        How times are estimated

        Time model : ride time between stops + time at stops + waiting for a trotro (+ walking), adjusted using measured 2021 trips. Times are always shown as a range.
